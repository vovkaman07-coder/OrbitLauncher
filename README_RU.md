# Orbit Launcher 2.0

Android-лаунчер на Kotlin с пользовательской иконкой из изображения, предоставленного владельцем проекта.

## Что есть в версии 2.0

- Режим приложения главного экрана Android (HOME).
- Автоматический список установленных приложений и быстрый поиск.
- Сетка 3–6 колонок, размер иконок, подписи, сортировка и избранное.
- Тёмная/светлая тема и смена акцентного цвета.
- Выбор пользовательских обоев из галереи Android.
- Настраиваемые жесты: двойное касание, свайп вниз, вверх и влево.
- Встроенные карточки-виджеты: дата/время, сохраняемая заметка и быстрые действия.
- Отдельный виджет Orbit для списка виджетов Android: быстрый переход к Boxy.
- Экран Boxy: подготавливает пользовательский запрос, копирует его и открывает официальный ChatGPT.
- Настройки и избранное сохраняются локально.

## Boxy и ChatGPT Free

Внешнее Android-приложение не может использовать бесплатный тариф ChatGPT как бесплатный API. У ChatGPT и API Platform раздельная система оплаты. Поэтому Boxy в этой версии работает как помощник-переходник: вводишь запрос, приложение копирует его, открывает официальный ChatGPT, после чего запрос можно вставить в чат и использовать бесплатный аккаунт.

Прямой ответ модели внутри собственного интерфейса потребовал бы отдельного API-доступа (обычно с оплатой по использованию) или отдельной локально запускаемой модели. API-ключ нельзя безопасно вшивать в APK: любой пользователь сможет извлечь его из приложения.

## Сборка APK через GitHub Actions

В проект включён файл `.github/workflows/build-apk.yml`. Он запускается при push в любую ветку, в том числе `app`, либо вручную.

1. Создай GitHub-репозиторий и загрузи **содержимое папки проекта** в корень репозитория: `app/`, `.github/`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`.
2. Открой вкладку **Actions**.
3. Выбери workflow **Build Orbit Launcher APK**. Если загрузка была через push, сборка запускается автоматически. Если нет — нажми **Run workflow**.
4. После зелёного статуса открой запуск workflow и скачай артефакт `OrbitLauncher-v2-debug-apk`.
5. Распакуй скачанный архив — внутри будет `app-debug.apk`.
6. Установи APK и выбери Orbit Launcher в системном выборе приложения главного экрана.

Технические версии: Android Gradle Plugin 8.7.3, Gradle 8.9, Kotlin 2.0.21, compileSdk 35, targetSdk 34, minSdk 26.

## Ограничения

- Встроенная заметка и карточки показываются на главном экране Orbit. Это не полноценный универсальный хост для размещения любых сторонних Android App Widgets.
- Отдельный системный виджет Orbit можно разместить на домашнем экране совместимого лаунчера. Его действие открывает Boxy.
- Boxy не отправляет запрос в ChatGPT автоматически: он копирует текст и открывает официальный сервис. Пользователь самостоятельно вставляет текст.
- Выбранные обои отображаются как фон интерфейса; Android хранит доступ к выбранному изображению через URI-разрешение.
- Полноценная работа системных виджетов внутри страницы Orbit потребовала бы реализации AppWidgetHost и управления жизненным циклом виджетов; в этой версии есть собственные встроенные карточки и отдельный AppWidgetProvider.

## Конфиденциальность

- В этой версии нет API-ключей, сетевого клиента к OpenAI или фоновой отправки пользовательского текста.
- Поиск приложений выполняется локально.
- Заметка и настройки хранятся локально в SharedPreferences.
- Разрешение `QUERY_ALL_PACKAGES` используется для отображения приложений на устройстве.
